# Projeto de Landing Page para montador de móveis

Objetivo é ter uma landing page clean, branca e sofisiticada e com o pensamento em mobile-first

Página com fundo branco e fonte Roboto como princial. 
Utilizar cores em marrom para realçar o destaque de móveis
Ter os modos light e dark para alternar e usar de acordo com o sistema que o usuário está utilizando.
- Utilize apenas HTML, CSS e Javascript



## Seção do HEADER


    Logo no canto esquerdo
    - Uma logo com um círculo e as letras JJ no meio feito com CSS
    - As cores podem ser com o fundo amarelo ou que combine com o site

    Menu no centro
    - Três ou mais opções para o menu (quem sou eu, meus projetos, contato, etc.)
    - Menu para mobile em formato de Hamburguer(3 traços que se expandem)


    No canto direito, se for necessário, pode colocar algum botão ou o que achar que é necessário


## Seção HERO 

    A hero deve ter altura 90vh, divido em 3 áreas horizontais:

Esquerda:
    Apenas uma headline com uma frase pequena sem destaque: o destaque será a foto no meio.
    Monte uma mensagem de um paragrafo que chame a atenção para adquirir os serviços do montador


Centro:
    Em destaque a imagem src/montador.jpg que é uma pessoa montando um móvel

Direita: 
    Uma lista de ponto chaves: 
        Domínio técnico
        Organização e método
        Precisão e atenção aos detalhes
        Uso correto de ferramentas
        Segurança
        Comunicação e atendimento
    Se quiser, pode usar emojis que se encaixam perfeitamente com o texto
